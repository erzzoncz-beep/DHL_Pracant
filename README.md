# DHL_Pracant – aktualizace aplikace

Toto veřejné úložiště hostí aktualizace Android aplikace DHL_Pracant.

- `latest.json` obsahuje číslo nejnovější verze, odkaz na APK a jeho kontrolní SHA-256.
- APK je podepsáno stejným podpisovým certifikátem jako stávající aplikace. Podpisový klíč není v tomto úložišti.
- Aplikace kontroluje aktualizaci při spuštění. QR kódy fungují offline.
- Android při instalaci aktualizace vždy vyžaduje potvrzení uživatele.

Protože je úložiště veřejné, APK a vložené pracovní QR kódy může stáhnout kdokoli.
